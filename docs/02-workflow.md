# 02. Рабочий процесс

Пошаговый процесс от исходного снимка до утверждённого результата. Все команды — PowerShell из корня проекта; кириллица осталась только в пути исходника, его всегда в кавычках.

## Шаг 0. Подготовка

```powershell
$root = "C:\My_projects\Photo"
$data = "$root\data"
$py = "$root\.venv\Scripts\python.exe"
$pp = "$root\src\photo_pipeline.py"
Set-Location $root

& $py $pp analyze "C:\Users\bur_s\OneDrive\Изображения\DSC00103.JPG"
```

Исходник лежит в OneDrive: `C:\Users\bur_s\OneDrive\Изображения\DSC00103.JPG`. Старый путь без `OneDrive` не работает. Все результаты и промежуточные файлы складывать в `data\`.

## Шаг 1. Вырезка

```powershell
& $py $pp cut "C:\Users\bur_s\OneDrive\Изображения\DSC00103.JPG" "$data\DSC00103-cut.png"
```

- Портретный режим включён по умолчанию.
- Время: 1–2 минуты. Не прерывать.
- Результат: `data\DSC00103-cut.png`, RGBA, размер исходника.

**Проверка:** открыть PNG на нейтральном фоне и посмотреть контур волос и плеч. Если по краю остался старый фон — повторить вырезку или обработать край вручную.

## Шаг 2. Выбор фона

Три пути:

1. **Генерация** — промпт → `data\bg\<имя>.jpg`.
2. **Реальное фото** — `data\bg\real_*.jpg` (Petworth, Gulf, Borre).
3. **Гибрид** — сгенерировать, затем доработать руками.

### Правило по свету

Главная проблема композита — не совпадает направление света: фон «светит» в одну сторону, а лицо и одежда освещены иначе. Поэтому для будущих фонов предпочтительнее:

- **без видимого источника света** — без солнца в кадре, без диска, без ярких лучей;
- **мягкий рассеянный свет** — облачность, тень, пасмурный день, глубокая аллея;
- **ровная освещённость** без длинных резких теней на земле.

Такой фон не спорит с освещением портрета, и композит выглядит естественнее. Если источник в кадре есть, его направление должно совпадать с направлением света на лице.

## Шаг 3. Генерация черновиков

```powershell
& $py $pp genbg "<prompt>" "$data\bg\park-a.jpg" --provider cloudflare --no-upscale
& $py $pp genbg "<prompt>" "$data\bg\park-b.jpg" --provider cloudflare --no-upscale
& $py $pp genbg "<prompt>" "$data\bg\park-c.jpg" --provider cloudflare --no-upscale
```

- `--no-upscale` — черновики быстрее, апскейл потом только для выбранного.
- Cloudflare отдаёт 1024×1024, скрипт кропает до 4:3 → 1024×768.
- Один и тот же промпт даёт разные результаты: модель недетерминирована.

**Сравнение:** собрать контактный лист из нескольких вариантов и оценить рядом:

```powershell
& $py "$root\src\contact_sheet.py" "$data\bg\park-a.jpg" "$data\bg\park-b.jpg" "$data\bg\park-c.jpg" --labels A B C --out "$data\bg\drafts-compare.jpg"
```

Скрипт требует Pillow, он есть в `.venv`.

## Шаг 4. Апскейл выбранного фона

```powershell
& $py $pp upscale "$data\bg\park-c.jpg" "$data\bg\park-c-4x.jpg"
```

- Real-ESRGAN ×4: 1024×768 → 4096×3072.
- Кредиты провайдера не тратятся, всё локально.
- Время зависит от CPU; на этой машине — несколько минут.

## Шаг 5. Композит

```powershell
& $py $pp composite "$data\DSC00103-cut.png" "$data\bg\park-c-4x.jpg" "$data\DSC00103-park-c.jpg" --blur 0.5
```

Параметры для апскейленного фона:

| Параметр | Значение | Почему |
|---|---:|---|
| `--blur` | 0.5–0.8 | Апскейленный фон иначе выглядит мыльным |
| `--shadow` | 0.22 | Базовая контактная тень |
| `--tone` | 1.06 | Лёгкая подгонка яркости фона |
| `--grain` | 4.5 | Зерно под старую фотографию |

Выходной размер — как у вырезки, 1632×1224.

## Шаг 6. Проверка

Чек-лист:

- [ ] направление света и теней совпадает с лицом и одеждой;
- [ ] линия горизонта не выше и не ниже правдоподобного уровня;
- [ ] масштаб деревьев и предметов не выглядит игрушечным;
- [ ] по контуру волос нет светлого или цветного ободка;
- [ ] цвет кожи не ушёл в зелень или оранжевый;
- [ ] зерно фона сопоставимо с зерном портрета;
- [ ] в фоне нет людей, текста, артефактов и «пластиковых» листьев;
- [ ] итоговое разрешение и формат устраивают.

Сравнение «до / после» удобно собирать тем же `src\contact_sheet.py`.

## Шаг 7. Правки

Типичные действия:

| Проблема | Что менять |
|---|---|
| Фон слишком резкий | увеличить `--blur` до 0.8–1.2 |
| Фон слишком тёмный/светлый | `--tone` в диапазоне 0.95–1.12 |
| Нет контакта с землёй | увеличить `--shadow` до 0.3 |
| Фон выглядит стерильно | увеличить `--grain` до 6–8 |
| Тени не совпадают | выбрать фон без источника света или перегенерировать |
| Ободок по волосам | пересобрать вырезку |

## Шаг 8. Фиксация результата

1. Создать папку `data\results\<дата>-<название>\`.
2. Скопировать итог, сравнение, исходник, вырезку и фон.
3. Посчитать SHA-256 и записать в `manifest.json`.
4. Добавить карточку результата в `docs\`.
5. Обновить `docs\README.md` и `AGENTS.md`.

Пример фиксации — `data/results/2026-11-17-park-c/` и [04-result-2026-11-17-park-c.md](04-result-2026-11-17-park-c.md).

## Контактный лист

```powershell
& $py "$root\src\contact_sheet.py" "$data\bg\park-a.jpg" "$data\bg\park-b.jpg" "$data\bg\park-c.jpg" --labels A B C --out "$data\bg\drafts-compare.jpg"
```

Скрипт делает превью 512×384 с подписями. Если файлов два, получается сравнение «до / после». Запускать из корня проекта или указывать абсолютный путь к скрипту.
